# 💊 MedSync

MedSync is a mobile healthcare application developed using Flutter and Firebase that helps users manage their medications effectively through scheduled reminders and medicine tracking.

## Features

* 🔔 Medicine reminder notifications
* 💊 Add, edit, and manage medicines
* 📋 View medicine schedules
* 📜 Track medication history
* 📷 Generate QR codes for medicine information
* ☁️ Secure data storage with Firebase
* 🎨 Simple and user-friendly interface

## Tech Stack

* Flutter
* Dart
* Firebase Authentication
* Firebase Realtime Database / Firestore
* Local Notifications

## Installation

```bash
git clone https://github.com/prabhadivya934-afk/Medsync-App.git
cd Medsync-App
flutter pub get
flutter run
```

## Project Objective

To help users organize their medications, receive timely reminders, and maintain a record of their medicine usage through a simple and efficient mobile application.
